# 📊 Sales Performance Dashboard – Power BI

An interactive **Sales Performance Dashboard built using Microsoft Power BI** to analyze sales, profit, quantity sold, orders, product categories, customer gender, regional performance, and monthly sales trends.

This project transforms sales data into meaningful business insights through interactive visualizations, KPIs, and filters to support **data-driven sales and business decision-making**.

---

## 📌 Project Overview

The **Sales Performance Dashboard** provides a comprehensive overview of sales performance across different product categories, regions, customer genders, and time periods.

The dashboard allows users to monitor important sales KPIs and explore business performance using interactive visualizations and slicers.

It provides insights into:

- 💰 Total Sales
- 📦 Total Quantity Sold
- 💵 Total Profit
- 🛒 Total Orders
- 🏷️ Product Category Performance
- 👥 Sales Contribution by Gender
- 📈 Monthly Sales Trends
- 🌍 Regional Sales Performance
- 💹 Profit by Product Category
